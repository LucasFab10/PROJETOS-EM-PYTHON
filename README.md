 🐍 PROJETOS-EM-PYTHON

Repositório dedicado aos meus estudos e projetos desenvolvidos durante minha jornada de aprendizado em **Python**.

Aqui estão reunidos exercícios, experimentos e projetos desenvolvidos ao longo dos estudos, desde os primeiros conceitos da linguagem até conteúdos mais avançados de programação estruturada e orientação a objetos.

 🎯 Objetivo

O objetivo deste repositório é **registrar minha evolução no aprendizado de Python**, mantendo meus exercícios e projetos organizados em um único lugar.

Nem todos os códigos aqui têm como objetivo ser aplicações profissionais. Muitos são exercícios desenvolvidos durante os estudos e representam etapas importantes do meu aprendizado.

Este repositório também funciona como um histórico da minha evolução: códigos mais simples representam os primeiros passos, enquanto projetos mais complexos mostram conceitos que fui aprendendo posteriormente.

 🚀 Em constante evolução

Este repositório continuará sendo atualizado conforme eu avanço nos estudos de Python e desenvolvo novos projetos.

Python é uma linguagem que pretendo continuar estudando e utilizando ao longo da minha formação e carreira.
